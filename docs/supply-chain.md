# Supply chain

What runs in Sia is pinned, verified, and updated deliberately — never silently.

## Python dependencies

- `pyproject.toml` declares floors; **`constraints.txt` is the lockfile**
  (generated by `make lock` via `uv pip compile`). The Docker image and every CI
  job install with `-c constraints.txt`, so builds resolve identical versions.
- The `lockfile-fresh` CI job fails when `pyproject.toml` drifts past the lock.
- `pip-audit` runs in CI against the locked environment; `pip-audit` and
  `bandit` themselves are pinned through the dev lock.
- Dependabot opens weekly PRs for pip, GitHub Actions, and the Docker base
  image; lockfile updates merge only after the full CI (tests + security job)
  passes, like any other PR.

## GitHub Actions

All third-party actions are pinned to commit SHAs (the tag is recorded in a
comment beside each pin). Dependabot keeps the SHAs current.

## Vendored frontend assets

The admin UI executes **no third-party-hosted code**: the default CSP is
`default-src 'self'` and these files ship in the package under
`app/static/vendor/`, fetched from each project's release tag:

| Asset | Version | Source | sha256 |
|---|---|---|---|
| `pico.min.css` | 2.0.6 | `github.com/picocss/pico` @ `v2.0.6` (`/css/pico.min.css`) | `dd5fd5591afd81ee21dcc117ad85c014dc3f1f19dc2d7b7d101ea0acc29274c2` |
| `htmx.min.js` | 2.0.4 | `github.com/bigskysoftware/htmx` @ `v2.0.4` (`/dist/htmx.min.js`) | `e209dda5c8235479f3166defc7750e1dbcd5a5c1808b7792fc2e6733768fb447` |
| `cytoscape.min.js` | 3.30.2 | `github.com/cytoscape/cytoscape.js` @ `v3.30.2` (`/dist/cytoscape.min.js`) | `83e8c54a6bec655bfd81df07df605649c268af69aeca67a5ea2da54ea42dac81` |

`scripts/verify_vendor_assets.py` checks every file against this manifest in CI
and in the test suite; an unexpected file in `vendor/` also fails.

### Upgrading an asset

1. Download the new version from the project's **release tag** (not a CDN).
2. Update `VENDOR_MANIFEST` in `scripts/verify_vendor_assets.py` and the table
   above (version, source ref, sha256) in the **same commit**.
3. Run the suite — the templates/CSP tests catch accidental CDN reintroduction.

## Container

Non-root user, SHA-pinned base via Dependabot docker updates, deps installed
from the lockfile. Secrets are environment-only (see the threat model).
